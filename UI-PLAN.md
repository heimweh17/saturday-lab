# Interface clarity plan
Palette: stadium navy #12304a, field blue #1768ac, paper white #ffffff, cool background #f4f7f9, muted ink #546879, scoreboard gold #d7aa45.
Typography: Barlow Condensed for sports headings; Source Sans 3 for controls and numerical descriptions.
Layout: left-aligned task navigation, a wide ranking table, and a quiet guide rail. Team pages separate tasks instead of stacking every analysis.

    Rankings | Teams & schedules | Compare teams    Model performance | How it works
    Season / rating snapshot
    Page purpose + one sentence of guidance
    Main table or team report                     Reading guide

    Team name / record / national rank
    Overview | Upcoming games | Results | Detailed stats
    Season ranking line (1 at top)
    Optional technical explanation

Principles: keep football results and predictions first; advanced research stays available through deliberate disclosure; use explicit snapshot dates and meaningful empty states. Preserve all data and formulas.
Review: retain the existing collegiate typography rather than introduce a generic dashboard card grid. Remove rhetorical headings and the large research sales panel. Rank movement is the visual centerpiece on team pages.
Rank chart: preseason plus each completed week, using the next pre-week snapshot (or latest for the final completed week), no duplicate latest point, no future weeks; include a table and CSV for exact values.
