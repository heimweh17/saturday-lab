# Observed passer context extension
User requested more sources and recruiting/roster alternatives. This stage is specified before inspecting the cohort stage's outer-year outcomes. It adds prior-season passer context from ESPN-derived player box scores (stable athlete IDs), never current-season future roster membership.

Parse both named ESPN passing columns and documented generic stat_1..stat_5 fallback (completions/attempts, yards, yards/attempt, TD, INT). Reject malformed rows and duplicate player/game/team records. For each game/team validate total passing attempts against the team box before using the group. Only FBS-v-FBS games contribute to a player's previous-season performance totals. Other completed games may establish which passers were last observed for a current FBS team. Rejected groups and coverage are published.

At each weekly cutoff, use passers and attempt shares from that team's most recent completed game. Their efficiency input is previous-season adjusted yards per attempt (yards + 20 TD - 45 INT), shrunk with 100 attempts toward the prior FBS league mean, centered on that mean and clipped to +/-5. Experience is attempt-share-weighted log(1+previous-season FBS attempts)/log(401). Before a current-season game has been observed, both context inputs are zero. An unseen player has neutral efficiency and zero prior FBS experience. No current-year future game determines membership, no inferred future starter/availability, and no claim that this metric is ESPN QBR or opponent-adjusted individual efficiency.

Use each outer year's three best distinct rating configurations from the cohort study's earlier-year validation list. For each, test all four existing component bundles, no passer context / efficiency only / experience only / both, and penalties 1/10: 96 candidates per annual search. Include the original no-context candidates so additional data are not compulsory. Each inner year trains on preceding years, choose pooled previous-three-year log loss and refit through outerYear-1. Rating-config preselection also uses only those earlier years. This is a hierarchical retrospective search, not an untouched holdout or an assertion that more data must help.
